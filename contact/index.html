Accessibility and ethics

I built this site by hand in HTML and CSS with accessibility in mind:

  • Semantic landmarks and a skip link on every page
  • One h1 per page with no skipped heading levels
  • Descriptive alt text on every image
  • Text contrast tested against WCAG AA
  • Visible focus states and full keyboard navigation
  • Descriptive link text rather than bare URLs

On content, I describe only work I can point to. Project pages name my specific contribution rather than the team's collective output, my Service Desk page contains no ticket or user information, and the recorded usability session referenced on the Pencil2D page is published with the participant's consent.
