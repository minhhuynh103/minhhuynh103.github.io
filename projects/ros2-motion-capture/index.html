Motion-Capture Jetmax Hiwonder Robotic Arm Control

Capstone project for NaturalPoint / OptiTrack

Overview

OptiTrack builds motion capture system that provides real-time 3D tracking of objects and people with millimeter-level accuracy. Their customers wanted to use that tracking data to drive a robotic arm automatically. Before this, moving the robotic arm required manual control, which was time-consuming and less precise without knowing the object's position.

The problem is that the two systems don't share a language. Motive knows the location of the markers sit in 3D space, but the robotic arm requires a different format of data. Therefore, our team built the layer in between, a set of ROS2 packages that reads position data from Motive and turns it into the arm movements. We built and tested it on a JetMax Hiwonder arm, with the interface designed so the same approach could extend to other robots.

My role

I was responsible for developing the jetmax_control layer, porting the ROS1 driver to ROS2, and creating the C++ to Python bridge. The other four teammates owned the hardware integration, the motion capture processing pipeline, the user interface design, and the testing framework.

Skills demonstrated

ROS2 · Python (rclpy) · C++ · Driver porting · Systems integration · Technical documentation

Impact and relevance

The successful porting of the ROS1 driver to ROS2 and the creation of the C++ to Python bridge enabled seamless integration between the motion capture system and the robotic arm, leading to improved control accuracy and real-time performance. This work was utilized by the development team for further testing and deployment.
